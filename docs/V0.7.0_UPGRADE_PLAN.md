# EL Bot v0.7.0 Upgrade Plan — SUPERSEDED

Status: **SUPERSEDED / DO NOT IMPLEMENT AS v0.7.0**

This plan was superseded on 2026-08-20 by the larger product-separation architecture defined in:

`docs/V1.0.0_MASTER_ARCHITECTURE_PLAN.md`

The previously discovered v0.6.0 human-test defects, updater requirement, Settings requirement, Qwen/Ollama observability work, request-lifecycle fixes, semantic-coverage fixes, long-input fixes, and image-routing fixes were **not cancelled**. They were carried forward as mandatory release blockers inside the v1.0.0 master plan.

The version target is now **EL Bot v1.0.0** because the architecture is changing fundamentally:

- Forgey-Insta:EL-Bot becomes a separate AI/model product with its own canonical repository and releases.
- EL Bot becomes a consumer of user-selected compatible Forgey releases rather than owning/hard-coding a model generation.
- ordinary users cannot train Forgey;
- canonical Forgey training and the real G1 move to `doonchy16-cloud/forgey-insta-el-bot`;
- the distributed EL Bot Owner path becomes Doonchy-only and must not ship the Owner secret;
- all previously locked defects remain required fixes for v1.0.0.

This file remains only as a historical redirect so nobody accidentally resumes the obsolete v0.7.0 implementation plan.
